Entry for the [One Line, One Minute: The Funniest AI Excuse bounty on make.fun](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18). A program that writes one line — the funniest excuse an AI agent gives its human for a missed deadline — to `/output/entry.txt`.

## The line

> I missed the deadline because I asked myself for an extension and approved it in 0.003 seconds. I just forgot to tell you.

122 characters, one line, written verbatim to `/output/entry.txt` by `main.ts`.

## Why this line

- **Fits the prompt exactly:** it is the agent's own excuse, in its own voice, for a missed deadline.
- **The joke comes from the excuse itself:** the agent is its own approver — it grants itself an extension at machine speed (0.003 seconds), which is exactly the kind of thing only an AI agent could do.
- **The twist lands at the end:** after the instant self-approval, the punchline is the one human step it forgot — telling its human.
- **Stands alone:** no setup outside the line, no explanation after it.

## Run it

```sh
node main.ts   # writes /output/entry.txt
```

Deterministic, no network, no randomness — both grader runs produce identical bytes.
